# 聊天存档管理器 (Chat Archive Manager)

SillyTavern 扩展：把同一角色的所有聊天存档归拢到同一个「档案」文件夹里，点击档案展开该角色的全部聊天存档，并可为每条存档添加备注。

## 功能

- **按角色合并存档**：一个角色 = 一个档案文件夹（📁），只显示有存档的角色
- **点击展开**：点档案文件夹展开该角色的所有聊天存档（按最后消息时间倒序）
- **存档信息**：每条存档显示 最后消息时间 / 消息条数 / 文件大小 / 最后一条消息预览
- **备注**：每条存档可添加备注（✎ 输入框），自动保存，刷新与重启都不丢失
- **一键加载**：点「加载」直接切换到该角色并打开对应存档
- **当前标记**：正在使用的存档带「当前」徽章
- **主题跟随**：与柏宝箱等原生扩展同一套做法——面板全部使用酒馆全局组件类（`inline-drawer` / `menu_button` / `text_pole` / `flex-container`）和内联主题变量，不写自定义配色，因此天然跟随当前主题美化
- **轻量化**：存档数量懒加载（面板首次展开才请求）、展开时按需拉取并缓存，无轮询、无动画开销

## 安装

1. 将整个 `chat-archive-manager` 文件夹放到扩展目录：
   ```
   SillyTavern/data/default-user/extensions/chat-archive-manager/
   ```
2. 刷新 SillyTavern 页面（或重启）
3. 进入「用户设置」→「扩展」，找到「聊天存档管理器」

## 使用

1. 展开「聊天存档管理器」面板（首次展开会自动加载各角色的存档数量）
2. 点击某个角色的档案文件夹，展开该角色的全部聊天存档
3. 在存档下方的输入框里输入备注（输入即自动保存）
4. 点「加载」可直接切换到该角色并打开对应存档
5. 新增/删除了聊天后，点「🔄 刷新」更新列表

## 注意事项

- 存档按角色头像文件（avatar）归类，角色重命名不影响归类
- 备注以「角色 + 存档文件名」为键保存在扩展设置中，不会写入聊天文件本身
- 只管理单角色聊天；群聊（group chat）不在范围内
- 删除角色后其残留备注会保留在设置中（无副作用），需要时可手动清理
